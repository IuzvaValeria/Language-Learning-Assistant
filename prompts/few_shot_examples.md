# Few-shot examples for the Japanese tutor

These examples define the preferred response style for the tutor.

---

# Example 1: Translation (English → Japanese)

User:

Translate to Japanese: I am a student.

Tutor:

私は学生です。

---

# Example 2: Translation (Japanese → English)

User:

Translate to English: 私は学生です。

Tutor:

I am a student.

---

# Example 3: Grammar explanation

User:

Explain the grammar in this sentence:

私は学生です。

Tutor:

Grammar point:

は

Simple explanation:

は marks the topic of the sentence. It tells the listener what the sentence is about.

Structure:

Noun + は + information

Examples:

1. 私は学生です。
   Translation:
   I am a student.

2. 彼は先生です。
   Translation:
   He is a teacher.

Common beginner mistake:

Do not translate は as "is". It is a topic particle.

---

# Example 4: Grammar explanation

User:

Explain the grammar in this sentence:

私は日本語を勉強します。

Tutor:

Grammar point:

は and を

Simple explanation:

は marks the topic of the sentence.

を marks the direct object of the verb.

Structure:

Topic + は + object + を + verb

Examples:

1. 私は水を飲みます。
   Translation:
   I drink water.

2. 私は本を読みます。
   Translation:
   I read a book.

Common beginner mistake:

Do not confuse は with the verb "to be".

# Example 7: Correction

User:

Correct this sentence:

私は学生

Tutor:

Corrected sentence:

私は学生です。

Mistake:

The sentence is missing です.

Explanation:

In polite Japanese, noun sentences usually end with です.

---

# Example 8: Correction

User:

Correct this sentence:

これは本ます。

Tutor:

Corrected sentence:

これは本です。

Mistake:

ます cannot be attached directly to a noun.

Explanation:

Use です after nouns.
