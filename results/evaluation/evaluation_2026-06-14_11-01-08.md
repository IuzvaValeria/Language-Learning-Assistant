# LLM Evaluation Report

## 1. Goal

The goal of this evaluation is to compare the base model with the LoRA-adapted model on tasks used in our Japanese-English learning assistant.

## 2. Evaluation Method

We use a small fixed test set. Each model answer is checked with simple keyword matching.

This is a rule-based evaluation, not a perfect semantic evaluation. It is suitable for this educational project because LLM answers may be phrased differently.

## 3. Model Information

- Base model: `ministral/Ministral-3b-instruct`
- LoRA path: `models\n5_lora_v4_translation_vocab_grammar`
- Date: 2026-06-14 11:01

## 4. Tested Tasks

- English → Japanese translation
- Japanese → English translation
- Grammar explanation
- Vocabulary explanation

## 5. Results

| Task | Base model | LoRA model | Change |
|---|---:|---:|---:|
| English → Japanese translation | 0/5, 0% | 5/5, 100% | +100 pp |
| Japanese → English translation | 2/5, 40% | 5/5, 100% | +60 pp |
| Grammar explanation | 0/5, 0% | 0/5, 0% | +0 pp |
| Vocabulary explanation | 2/5, 40% | 5/5, 100% | +60 pp |
| **Total** | **4/20, 20%** | **15/20, 75%** | **+55 pp** |

## 6. Interpretation

The LoRA model is expected to perform better because it was trained on task-specific examples from our project dataset.

The largest improvement is expected in translation, because translation examples are the largest part of the training dataset.

## 7. Limitations

This evaluation uses keyword matching. A response may be counted as incorrect even if it is partially correct, or counted as correct if it contains the keyword but the full explanation is weak.

For the final project evaluation, we also manually inspect several model answers.
